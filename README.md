# Video Stats Dashboard

A minimal, fast web page to compare video performance and visualize key metrics with clean charts.

Built with: `HTML` `Tailwind CSS` `Chart.js` `Vanilla JS`

---
>  **Check out the live application here:** [View ](https://videos-stats-dashboard.netlify.app/)

---

##  Features

- **Video Stats Comparison**  
  Compare multiple videos side by side. Add `Views`, `Likes`, `Comments` and see which video performed better instantly.
- **Minimal UI**  
  No clutter. Everything you need is on one screen.
- **Interactive Charts**  
  Visualize metrics with responsive bar charts powered by Chart.js.  
  Supports large numbers from `50` to `1M+` with automatic `K` / `M` formatting.
- **Logarithmic Scale Support**  
  Toggle between linear and log scale so small values like 50 comments don't get lost next to 1M views.
- **Responsive Design**  
  Works perfectly on desktop, tablet, and mobile. Built with Tailwind CSS.
- **Customizable Metrics**  
  Easily add more metrics like `Shares`, `Watch Time`, `CTR` to the dataset.
- **Lightweight & Fast**  
  No frameworks needed. Pure JS + Tailwind CDN. Loads in under 1 second.
-**Dark mode**
   Dark mode button is available.

## Tech Stack
| Tech | Purpose |
| --- | --- |
